# Myostoox 1.0

**First public release** — audio/video player for Debian Trixie XFCE, Lubuntu 26.04 and GTK desktops (LXQt / XFCE).

---

## English

### What’s new

Initial release of **Myostoox**:

- Full playlist (add files / folders, import & export `.m3u` / `.m3u8` / `.pls`)
- Internet radios and TV / M3U bouquets
- Experimental CD, DVD and Blu-ray playback
- 10-band graphic equalizer, pitch / tempo, spectrum visualizer
- Subtitles (embedded and external), LRC lyrics
- Multiple UI themes, MPRIS2 integration, mini-player
- Single-instance behaviour (files from the file manager open in the existing window)
- Desktop notifications and screensaver inhibit during video (when available)

### Download

Attach / download:

- **`myostoox_1.0-1_all.deb`** — installable package (architecture *all*)

### Install

```bash
sudo apt install ./myostoox_1.0-1_all.deb
```

If dependencies are missing, run:

```bash
sudo apt install -f
```

Then launch **Myostoox** from the application menu, or:

```bash
myostoox
```

### Requirements

Debian / Ubuntu / Lubuntu with Python 3, GTK 3 and GStreamer (see README).  
Tested with a focus on **Debian XFCE Trixie** and **Lubuntu 26.04 LTS**.
