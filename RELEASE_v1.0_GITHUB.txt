Myostoox 1.0 — First public release

Audio/video player for Lubuntu and lightweight GTK desktops (LXQt / XFCE).
Python 3 + GTK 3 + GStreamer.

Highlights:
• Playlist (import/export m3u, m3u8, pls)
• Internet radios & TV / M3U bouquets
• Experimental CD / DVD / Blu-ray
• Equalizer, pitch/tempo, spectrum
• Subtitles & LRC lyrics
• Themes, MPRIS2, mini-player
• Single-instance + optional notifications

Install:
  sudo apt install ./myostoox_1.0-1_all.deb
